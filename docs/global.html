(async) WDwdataTweqmp(st, optopt) → {Object}

Description:

  • 基於檔案之下載台灣氣象署FTP地震數據與任務建構器

    執行階段最新hash數據放置於fdDwAttime，前次hash數據會於結束前自動備份至fdDwCurrent

    執行階段最新數據放置於fdDwStorageTemp，前次數據放置於fdDwStorage，於結束前會將fdDwStorage清空，將fdDwStorageTemp複製至fdDwStorage

    預設之funAdd與funModify於解析數據檔前會先以checkData檢測內容，內容殘缺(傳輸中斷之殘檔等)時不寫出任何結果、不動既有結果， 改以事件紀錄(type為error，event為proc-add-check-data或proc-diff-check-data，msg為checkData之固定詞彙訊息，不含內容)通知後略過該檔， 不中止本輪其餘檔案之處理；該檔已隨本輪下載進入fdDwStorage，待下輪遠端檔案重新下載後hash不同時，會再以modify處理。 自訂funAdd與funModify若呼叫parseData，遇殘缺內容時parseData會拋錯，w-dwdata-ftp所用之排程器(w-data-scheduler)將取消本輪其餘檔案之處理，須自行try-catch或先以checkData檢測

    預設流程略過之新增檔案，排程器仍視為已處理並記入任務清單(fdTaskCpSrc)，故下游依任務清單取用者，須另依type為error之事件判斷該檔是否已有結果

checkData(c) → {Object}

Description:

  • 檢測台灣氣象署地震PGA數據檔(*-townshipInt-All.txt)內容是否完整可解析，不拋錯

    判準取自使用端提供之真實檔語料(3693檔)之共同結構，供使用端於接收檔案時先行驗證，亦為parseData之前置檢測，兩者判定一致：

    1.輸入須為字串，且不含NUL字元與取代字元U+FFFD(NUL填充與編碼損毀之徵象)

    2.須恰有1行「觀測時間：」，其值須為真實存在之日期時間，格式YYYY-MM-DD HH:mm:ss(UTC+0，加8小時後須仍為4位數年份，以使parseData之id為14位數字)

    3.每一Staname=起始行須為完整測站列：依序為Staname、Stacode、Stalon、Stalat、震度、PGA(V)、PGA(NS)、PGA(EW)共8欄，或其後再加PGV(V)、PGV(NS)、PGV(EW)共11欄，各欄值非空

    4.至少須有1筆測站列

    5.內容須以換行結束(真實檔3693檔皆是)，用以偵測傳輸中斷所致之尾端截斷

    不檢查測站數、縣市與末站等氣象署設定面之值(日後設定變更時會誤拒完整檔)

    限制：恰於換行處被截斷、且已含至少1筆測站列之檔案，其結構與完整檔相同，無法於內容層偵測，須於下載層以遠端檔案大小核對

    失敗訊息為固定詞彙，只含參數名與位置(行號)，不含內容
